# LAB 4: JIT Compiler Analysis & Optimization

## DURACION ESTIMADA
3-4 horas

## OBJETIVO
Entender como funciona JIT compiler, observar optimizaciones en accion, analizar codigo generado y entender cuando desactivarlo.

## TAREAS

### Parte 1: JIT Compilation Levels
- Escribir programa con metodo hot (llamado muchas veces)
- Habilitar JIT logging: -XX:+PrintCompilation
- Observar tiered compilation: Interpreter → C1 → C2
- Identificar en logs: nivel de compilacion, metodos compilados
- Medir diferencia de performance interpretado vs compilado

### Parte 2: Inlining
- Crear jerarquia de metodos pequeños que se llaman entre si
- Habilitar -XX:+UnlockDiagnosticVMOptions -XX:+PrintInlining
- Observar que metodos se inlinean
- Experimentar con metodos muy largos (no se inlinean)
- Probar @ForceInline (JDK internal) vs metodos normales

### Parte 3: Escape Analysis
- Escribir codigo donde objetos no escapan metodo
- Verificar con -XX:+PrintEscapeAnalysis
- Casos:
  - Objeto creado y usado solo localmente (stack allocation)
  - Objeto que escapa via return (heap allocation)
  - Scalar replacement: objeto eliminado completamente
- Medir impacto en performance y GC

### Parte 4: Loop Optimizations
- Implementar loops con codigo invariante
- Observar loop unrolling
- Experimentar con loop invariant code motion
- Dead code elimination en loops

### Parte 5: Deoptimization
- Crear codigo con polymorphic call sites
- Observar optimistic optimization
- Forzar deoptimization agregando nueva implementacion
- Monitorear con -XX:+PrintDeoptimization
- Analizar costo de deoptimizacion

### Parte 6: Generated Code Analysis
- Usar -XX:+UnlockDiagnosticVMOptions -XX:+PrintAssembly (requiere hsdis)
- Analizar assembly generado para metodo hot
- Comparar codigo: antes vs despues de optimizaciones
- Identificar instrucciones SIMD si aplica

## ENTREGABLES
- Programas de prueba para cada optimizacion
- Scripts con flags de JVM
- findings.md con:
  - Logs de compilacion analizados
  - Tablas de performance: interpretado vs C1 vs C2
  - Explicacion de cuando ocurre cada optimizacion
  - Trade-offs de JIT: warmup time vs peak performance
  - Casos donde desactivar JIT tiene sentido
