# LAB 10: Serialization Deep Dive & Security

## DURACION ESTIMADA
3 horas

## OBJETIVO
Dominar mecanismos de serializacion en Java, entender riesgos de seguridad, implementar custom serialization y comparar alternativas modernas.

## TAREAS

### Parte 1: Serializable Basico
- Implementar clase Serializable simple
- Serializar a archivo y deserializar
- Experimentar con serialVersionUID:
  - Sin definir (generado automatico)
  - Definido explicitamente
  - Cambiar clase y observar InvalidClassException
- transient keyword: fields que no se serializan
- static fields no se serializan

### Parte 2: Custom Serialization
Implementar writeObject/readObject para:
- Encriptar datos antes de serializar
- Validar invariantes durante deserializacion
- Optimizar serializacion (ej: comprimir strings)
- Mantener compatibilidad con versiones anteriores

Casos:
- Clase con password: no serializar directamente
- Clase con cache derivado: recalcular en deserializacion
- Clase con referencias circulares

### Parte 3: Externalizable Interface
- Implementar Externalizable para control total
- Comparar con Serializable
- Performance: Externalizable mas rapido pero mas codigo
- Casos de uso apropiados

### Parte 4: Serialization Security
Explorar vulnerabilidades:
- Deserialization attacks (crear objetos maliciosos)
- Gadget chains (explotar libraries en classpath)
- DoS via deserializacion de objetos gigantes

Mitigaciones:
- ObjectInputFilter (Java 9+)
- Whitelist de clases permitidas
- Validacion en readObject
- Usar alternativas seguras (JSON, Protobuf)

### Parte 5: Alternative Serialization
Comparar Java serialization con:

**JSON:**
- Jackson library
- Gson library
- Interoperabilidad con otros lenguajes
- Legibilidad humana

**Binary:**
- Protocol Buffers
- Apache Avro
- MessagePack

**XML:**
- JAXB

Medir para cada uno:
- Tamano serializado
- Velocidad de serializacion/deserializacion
- Facilidad de uso
- Versionado de esquema

### Parte 6: Advanced Topics
- Serialization proxy pattern
- Singleton pattern con serializacion (readResolve)
- Enum serialization (especial handling)
- Serialization y herencia
- SerialPersistentFields para control fino
