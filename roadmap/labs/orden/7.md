# LAB 7: Lock-Free Programming & Atomic Operations

## DURACION ESTIMADA
3 horas

## OBJETIVO
Dominar programacion lock-free usando Atomic classes, entender memory ordering, implementar estructuras de datos concurrentes sin locks.

## TAREAS

### Parte 1: Atomic Variables
Experimentar con:
- AtomicInteger, AtomicLong, AtomicBoolean
- AtomicReference, AtomicStampedReference, AtomicMarkableReference
- Operaciones: get, set, compareAndSet (CAS), getAndIncrement, etc.
- AtomicIntegerArray y AtomicReferenceArray

Implementar contadores concurrentes:
- Con synchronized
- Con AtomicInteger
- Benchmark ambos bajo alta contencion

### Parte 2: Compare-And-Swap (CAS)
- Entender algoritmo CAS
- Implementar stack lock-free usando CAS (Treiber Stack)
- Implementar queue lock-free usando CAS (Michael-Scott Queue)
- Manejar ABA problem con AtomicStampedReference

### Parte 3: Memory Ordering
- Entender Java Memory Model
- Experimentar con volatile vs non-volatile
- Casos de visibility bugs sin volatile
- Happens-before relationships
- Operaciones acquire/release semantics

### Parte 4: AtomicFieldUpdater
- Usar AtomicIntegerFieldUpdater para actualizar fields sin boxing
- Casos de uso: reducir memory overhead vs Atomic classes
- Trade-offs: performance vs complejidad

### Parte 5: LongAdder & LongAccumulator
- Comparar AtomicLong vs LongAdder bajo alta contencion
- Implementar contador distribuido con LongAdder
- Usar LongAccumulator para agregaciones custom

### Parte 6: Lock-Free Data Structure
Implementar una de estas estructuras:
- Lock-free stack
- Lock-free queue
- Lock-free hash map (simplificado)
- Lock-free linked list

Validar:
- Correctness: no race conditions, no data loss
- Progress guarantee: lock-free (al menos un thread progresa)
- Performance vs version con locks

### Parte 7: Benchmark Contention
Crear escenarios con diferentes niveles de contencion:
- Low contention: pocos threads
- High contention: muchos threads
- Bursty contention: picos intermitentes

Comparar:
- synchronized
- ReentrantLock
- Atomic operations
- Lock-free structures
