# LAB 12: Virtual Threads vs Platform Threads (Java 21+)

## DURACION ESTIMADA
3-4 horas

## OBJETIVO
Entender Virtual Threads (Project Loom), comparar con platform threads tradicionales, medir performance y aprender cuando usar cada uno.

## TAREAS

### Parte 1: Virtual Threads Basics
- Crear virtual thread con Thread.startVirtualThread()
- Crear con Executors.newVirtualThreadPerTaskExecutor()
- Comparar con platform thread
- Thread.isVirtual() para identificar tipo
- Lifecycle identico a platform threads

### Parte 2: Scalability Test
Crear programa que:
- Lanza N threads concurrentes (N = 10, 100, 1K, 10K, 100K, 1M)
- Cada thread duerme X segundos y termina

Comparar:
- Platform threads (ThreadPoolExecutor)
- Virtual threads (newVirtualThreadPerTaskExecutor)

Medir:
- Maximo threads simultaneos soportados
- Uso de memoria
- CPU usage
- Tiempo total de ejecucion

Observar: Platform threads limitados por OS, Virtual threads millones sin problema.

### Parte 3: I/O Bound Workload
Implementar servidor HTTP simple que:
- Maneja request con delay simulando I/O (DB query, API call)
- Version 1: Platform threads pool
- Version 2: Virtual threads

Load test con:
- 1000 requests concurrentes
- 10000 requests concurrentes

Medir:
- Throughput (req/sec)
- Latencia (p50, p95, p99)
- Thread count
- Memory usage

### Parte 4: CPU Bound Workload
Implementar tarea CPU-intensive (ej: calcular primos)

Comparar:
- Platform threads (ForkJoinPool)
- Virtual threads

Resultado esperado: Virtual threads NO mejoran CPU-bound tasks.

### Parte 5: Structured Concurrency (Preview)
- Usar StructuredTaskScope para manejar subtareas
- Casos:
  - ShutdownOnFailure: si una falla, cancelar resto
  - ShutdownOnSuccess: primera que complete, cancelar resto
- Comparar con CompletableFuture tradicional

### Parte 6: Pinning Problems
Identificar casos donde virtual thread "pinna" platform thread:
- synchronized blocks
- Native methods

Experimentar:
- synchronized: causa pinning (usar ReentrantLock en su lugar)
- Medir impacto de pinning en escalabilidad

### Parte 7: Thread-Local Variables
- ThreadLocal con virtual threads: riesgo de memory leak
- Usar scoped values (preview) como alternativa
- Comparar comportamiento y performance

### Parte 8: Migration Strategy
Dado codigo legacy con platform threads:
- Identificar oportunidades de migracion
- Refactor thread pools a virtual threads
- Validar que no hay pinning problems
- Medir mejora

  - Casos de uso ideales para virtual threads
