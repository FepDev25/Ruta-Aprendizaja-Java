# LAB 1: Bytecode Analysis & ClassLoader Deep Dive

## DURACION ESTIMADA
3-4 horas

## OBJETIVO
Comprender como funciona el ClassLoader, analizar bytecode generado y crear un ClassLoader personalizado para carga dinamica de clases.

## TAREAS

### Parte 1: Analisis de Bytecode
- Escribir clase simple Java con metodos, campos, constructores
- Compilar y examinar archivo .class con herramienta javap
- Identificar: constant pool, metodos, descriptores, instrucciones bytecode
- Escribir clase con diferentes niveles de optimizacion (-O, -g)
- Comparar bytecode generado
- Analizar bytecode de clase con lambda vs clase anonima

### Parte 2: ClassLoader Hierarchy
- Crear programa que imprima jerarquia de ClassLoaders
- Identificar Bootstrap, Platform (Extension), Application ClassLoaders
- Cargar clase desde diferentes ClassLoaders
- Experimentar con parent delegation model
- Intentar romper el modelo y observar consecuencias

### Parte 3: Custom ClassLoader
- Implementar ClassLoader personalizado que:
  - Carga clases desde directorio especifico fuera del classpath
  - Implementa hot-reload: detecta cambios en .class y recarga
  - Aplica transformacion al bytecode antes de definir clase (ej: logging injection)
- Probar casos: ClassNotFoundException, NoClassDefFoundError
- Experimentar con class isolation entre ClassLoaders

### Parte 4: Class Initialization
- Crear jerarquia de clases con static blocks
- Determinar orden exacto de inicializacion
- Experimentar con lazy initialization
- Probar cuando se ejecutan static blocks vs instance initialization blocks

## ENTREGABLES
- Script ejecutable de cada experimento
- findings.md con:
  - Estructura de archivo .class explicada
  - Como funciona parent delegation
  - Casos de uso de custom ClassLoaders
  - Orden de inicializacion de clases documentado
  - Problemas encontrados y soluciones
