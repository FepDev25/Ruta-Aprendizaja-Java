# LAB 8: JMH Microbenchmarking Mastery

## DURACION ESTIMADA
3 horas

## OBJETIVO
Dominar JMH (Java Microbenchmark Harness) para medir performance correctamente, evitar trampas comunes y generar benchmarks confiables.

## TAREAS

### Parte 1: Setup & Basics
- Configurar proyecto con JMH
- Escribir primer benchmark simple
- Entender anotaciones: @Benchmark, @BenchmarkMode, @State
- Modos: Throughput, AverageTime, SampleTime, SingleShotTime
- Ejecutar y leer resultados

### Parte 2: JMH Trampas Comunes
Experimentar con:
- Dead code elimination: JIT elimina codigo que no usa resultado
- Constant folding: JIT precalcula constantes
- Loop unrolling impact

Aprender a evitar con:
- Blackhole.consume()
- @CompilerControl
- Return values de @Benchmark

### Parte 3: State Management
- @State(Scope.Thread): estado por thread
- @State(Scope.Benchmark): compartido entre threads
- @State(Scope.Group): para grupos
- @Setup y @Teardown: niveles (Trial, Iteration, Invocation)
- @Param: parametrizar benchmarks

### Parte 4: Warmup & Iterations
- Entender warmup iterations vs measurement iterations
- Configurar forks para estabilidad
- Ajustar tiempo por iteracion
- Analizar varianza entre forks

### Parte 5: Benchmarks Comparativos
Crear benchmarks para comparar:
- ArrayList vs LinkedList (get, add, iterate)
- HashMap vs ConcurrentHashMap bajo contencion
- String concatenation: + vs StringBuilder vs String.format
- Stream vs for loop
- Synchronized vs ReentrantLock vs Atomic

### Parte 6: Profilers Integration
- Integrar profilers: -prof gc, -prof stack, -prof perf
- Analizar GC impact en benchmarks
- Identificar hotspots con stack profiler
- Usar perf (Linux) para analisis bajo nivel

### Parte 7: Asymmetric Benchmarks
- @Group y @GroupThreads para modelar producer/consumer
- Benchmark con diferentes ratios (1 writer, N readers)
- Medir performance de read-write locks

### Parte 8: Best Practices
- Como estructurar suite de benchmarks
- Interpretar resultados: mean, p99, p999
- Detectar regresiones de performance
- Integrar JMH en CI/CD

## ENTREGABLES
- Suite de benchmarks comparativos
- findings.md con:
  - Guia de JMH: anotaciones, modos, configuracion
  - Catalogo de trampas y como evitarlas
  - Resultados de benchmarks con analisis
  - Graficos comparativos
  - Checklist de best practices
  - Template de benchmark para reutilizar
