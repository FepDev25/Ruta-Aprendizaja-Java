# LAB 6: NIO Advanced Patterns

## DURACION ESTIMADA
4 horas

## OBJETIVO
Dominar NIO (Non-blocking I/O) con Buffers, Channels, Selectors. Implementar servidor echo non-blocking y comparar performance con blocking I/O.

## TAREAS

### Parte 1: Buffer Operations
- Crear ByteBuffer y experimentar con:
  - Allocate vs allocateDirect
  - put/get operations
  - flip, clear, compact, rewind
  - mark/reset
  - Bulk operations
- Implementar protocolo custom usando ByteBuffer
- Manejo de buffer overflow/underflow

### Parte 2: Channels
- FileChannel: lectura/escritura eficiente
- SocketChannel: comunicacion TCP
- ServerSocketChannel: aceptar conexiones
- DatagramChannel: UDP
- Transferir datos entre channels (transferTo/transferFrom)

### Parte 3: Selector-based Server
Implementar servidor echo TCP non-blocking:
- Single thread manejando multiples conexiones
- Usar Selector para multiplexing I/O
- Registrar channels con SelectionKey
- Manejar eventos: ACCEPT, READ, WRITE
- Buffer pooling para reducir allocations
- Casos edge: partial reads, partial writes, client disconnect

### Parte 4: Memory-Mapped Files
- Mapear archivo grande a memoria
- Comparar performance: FileInputStream vs FileChannel vs MappedByteBuffer
- Casos de uso: lectura random access, archivos gigantes
- Memory-mapped file para IPC

### Parte 5: Scatter/Gather I/O
- Usar scatter read (un read a multiples buffers)
- Usar gather write (multiples buffers a un write)
- Implementar protocolo con header + body usando scatter/gather

### Parte 6: Performance Comparison
Benchmark:
- Blocking I/O (InputStream/OutputStream) multi-threaded
- Non-blocking I/O (NIO Selector) single-threaded
- Non-blocking I/O (NIO Selector) multi-threaded

Medir bajo diferentes cargas:
- 10 conexiones simultaneas
- 100 conexiones
- 1000 conexiones

Metricas:
- Throughput (MB/s)
- Latencia (p50, p99)
- CPU usage
- Memory usage
- Thread count

## ENTREGABLES
- Servidor echo NIO completo
- Cliente de prueba
- Scripts de benchmark
- findings.md con:
  - Diagramas de ciclo de vida de Buffer
  - Flujo de eventos con Selector
  - Graficos de performance: blocking vs non-blocking
  - Trade-offs: complejidad vs escalabilidad
  - Cuando usar NIO vs tradicional I/O
