# LAB 5: Reflection & Dynamic Proxies Deep Dive

## DURACION ESTIMADA
3 horas

## OBJETIVO
Dominar Reflection API, crear proxies dinamicos, entender MethodHandles y comparar performance de cada approach.

## TAREAS

### Parte 1: Reflection Basica
- Obtener Class object de diferentes formas
- Inspeccionar: fields, methods, constructors, annotations
- Modificar valores de fields privados
- Invocar metodos privados
- Crear instancias sin constructor publico
- Manipular arrays via reflection

### Parte 2: Dynamic Proxies
Crear proxy dinamico para:
- Interface logging: loggear cada llamada a metodo
- Interface timing: medir tiempo de ejecucion
- Interface caching: cachear resultados de metodos
- Interface validation: validar parametros antes de llamada
- Implementar InvocationHandler robusto

Casos de uso:
- Repository pattern con lazy loading
- AOP-style cross-cutting concerns
- RPC/RMI simulation

### Parte 3: MethodHandles (Modern Reflection)
- Crear MethodHandles para metodos, constructores, fields
- Comparar sintaxis vs Reflection clasica
- Usar MethodHandle.invoke vs invokeExact
- Implementar method dispatch con MethodHandles
- Crear MethodHandle combinators (filter, guard, fold)

### Parte 4: Annotation Processing
- Crear custom annotations para validacion
- Implementar processor que lee annotations en runtime
- Casos:
  - @NotNull validator
  - @Range validator
  - @Email validator
- Crear mini-framework de validacion usando reflection

### Parte 5: Performance Comparison
Benchmark comparando:
- Direct method call (baseline)
- Reflection (Method.invoke)
- MethodHandle.invoke
- MethodHandle.invokeExact
- Dynamic proxy

Medir:
- Throughput (ops/sec)
- Latencia
- Memory overhead
- JIT optimization impact

### Parte 6: VarHandle (Java 9+)
- Usar VarHandle para acceso a fields
- Operaciones atomicas con VarHandle
- Comparar con Atomic classes y Unsafe
- Memory ordering guarantees

## ENTREGABLES
- Implementaciones de cada tecnica
- Benchmark con JMH
- findings.md con:
  - Comparacion reflection vs MethodHandles vs directo
  - Casos de uso apropiados para cada approach
  - Performance overhead documentado
  - Limitaciones de cada tecnica
  - Best practices
