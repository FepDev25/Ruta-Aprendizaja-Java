# PROYECTO 5: Parallel Web Scraper & Data Pipeline

## FASE
Concurrencia & Performance

## DESCRIPCION
Sistema de web scraping distribuido que descarga contenido de multiples sitios en paralelo, procesa datos, detecta cambios y almacena resultados. Enfoque en concurrencia, performance y manejo eficiente de recursos.

## OBJETIVOS FUNCIONALES

### Funcionalidades core:

**Scraping engine:**
- Configurar multiples fuentes (URLs) para monitorear
- Descargar paginas HTML en paralelo con rate limiting
- Parsear HTML y extraer datos especificos (selectores CSS/XPath)
- Detectar cambios desde ultima ejecucion
- Reintentar descargas fallidas con backoff exponencial
- Respetar robots.txt

**Processing pipeline:**
- Transformar datos extraidos (limpieza, normalizacion)
- Validar datos segun reglas configurables
- Enriquecer datos (ej: geocoding, sentiment analysis)
- Almacenar en base de datos o archivos
- Pipeline de procesamiento configurable (stages)

**Scheduling & monitoring:**
- Ejecutar scraping en intervalos programados
- Monitorear estado: URLs en cola, procesadas, fallidas
- Metricas: tiempo por URL, throughput, errores
- Pausar/reanudar trabajos
- Cancelar trabajos en ejecucion sin corrupcion de datos

### Requisitos tecnicos:
- Thread pools configurables (tamano dinamico)
- Work-stealing queue para balanceo de carga
- CompletableFuture para operaciones asincronas
- Connection pooling para HTTP clients
- Manejo de timeouts y circuit breaker para URLs lentas
- Sincronizacion sin deadlocks
- Profiling de performance (CPU, memoria, threads)

### Casos de uso:
- Monitorear precios de productos en e-commerce
- Agregar noticias de multiples fuentes
- Detectar cambios en paginas monitoreadas
- Extraer datos estructurados de listados
