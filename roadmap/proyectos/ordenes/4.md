# PROYECTO 4: Expense Tracker - Personal Finance Manager

## FASE
Backend & Data

## DESCRIPCION
Sistema completo de gestion de finanzas personales con categorias, presupuestos, reportes y graficos de gastos. Incluye API REST y procesamiento de datos.

## OBJETIVOS FUNCIONALES

### Funcionalidades core:

**Gestion de transacciones:**
- Registrar ingresos y gastos con: monto, categoria, fecha, descripcion, metodo de pago
- Editar y eliminar transacciones
- Adjuntar etiquetas personalizadas a transacciones
- Soportar multiples cuentas (efectivo, banco, tarjeta)

**Categorias y presupuestos:**
- Crear categorias jerarquicas (ej: Transporte > Gasolina, Uber)
- Definir presupuestos mensuales por categoria
- Alertas cuando se excede X% del presupuesto

**Reportes y analisis:**
- Resumen mensual: total ingresos, gastos, balance
- Gastos por categoria (absoluto y porcentaje)
- Tendencias: comparacion mes a mes
- Top 5 gastos mas grandes del periodo
- Exportar reportes a PDF o CSV

**Busqueda y filtros:**
- Filtrar por: rango de fechas, categoria, monto minimo/maximo, metodo de pago
- Buscar por descripcion
- Ordenar por fecha, monto, categoria

### Requisitos tecnicos:
- API REST con Spring Boot
- Base de datos relacional con constraints apropiados
- Generacion de reportes con bibliotecas de PDF (iText o similares)
- Scheduled tasks para calcular resumen mensual automatico
- Validaciones: montos positivos, fechas validas, categorias existentes
- Tests de integracion con cobertura > 80%

### Reglas de negocio:
- Montos deben ser positivos
- No se pueden eliminar categorias con transacciones asociadas
- Presupuesto debe ser mayor a cero
- Fecha de transaccion no puede ser futura
- Balance de cuenta no puede quedar negativo (opcional: modo credito)
