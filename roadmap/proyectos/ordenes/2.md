# PROYECTO 2: Log File Analyzer

## FASE
Fundamentos

## DESCRIPCION
Analizador de archivos de logs que procesa multiples formatos, extrae metricas, detecta patrones de errores y genera reportes.

## OBJETIVOS FUNCIONALES

### Funcionalidades core:
- Leer archivos de log de diferentes formatos (Apache, Nginx, custom)
- Parsear lineas de log y extraer campos (timestamp, nivel, mensaje, IP, etc)
- Filtrar logs por: nivel (ERROR, WARN, INFO), rango de fechas, patron regex
- Generar estadisticas: total de lineas, distribucion por nivel, top 10 IPs
- Detectar anomalias: picos de errores, IPs sospechosas (muchas requests)
- Exportar reportes en formato texto, CSV o JSON

### Requisitos tecnicos:
- Soportar archivos grandes (streaming line-by-line, no cargar todo en memoria)
- Configuracion mediante archivo properties
- Procesamiento eficiente con Streams API
- Manejo de multiples formatos de fecha/hora
- Validacion robusta de formato de log

### Casos de uso:
- Analizar logs de servidor web para detectar errores 500
- Identificar IPs con comportamiento anormal
- Generar reporte diario de actividad
- Buscar patrones especificos en mensajes de error
