# PROYECTO 1: CLI Task Manager

## FASE
Fundamentos

## DESCRIPCION
Sistema de gestion de tareas por linea de comandos con persistencia en archivo. Permite crear, listar, modificar, eliminar y buscar tareas.

## OBJETIVOS FUNCIONALES

### Comandos requeridos:
- add: Agregar nueva tarea con titulo, descripcion, prioridad, fecha limite
- list: Listar todas las tareas con filtros (estado, prioridad, fecha)
- update: Modificar tarea existente por ID
- delete: Eliminar tarea por ID
- complete: Marcar tarea como completada
- search: Buscar tareas por palabra clave
- stats: Mostrar estadisticas (total, completadas, pendientes, por prioridad)

### Requisitos tecnicos:
- Interfaz de linea de comandos interactiva
- Validacion de entrada de usuario
- Manejo de errores con mensajes claros
- Persistencia en archivo JSON o CSV
- Los datos deben sobrevivir entre ejecuciones
- Formato de salida legible (tablas ASCII)

### Restricciones:
- NO usar frameworks externos (solo JDK standard)
- NO usar bases de datos
- Implementar desde cero todas las estructuras
