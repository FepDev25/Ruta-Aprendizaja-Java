# PROYECTO 6: Multi-Client Chat Server

## FASE
Concurrencia & Performance

## DESCRIPCION
Servidor de chat multiusuario con soporte para salas, mensajes privados, historial persistente y manejo de alta concurrencia. Implementacion con sockets TCP y arquitectura non-blocking.

## OBJETIVOS FUNCIONALES

### Funcionalidades core:

**Servidor:**
- Aceptar multiples conexiones simultaneas (100+ clientes)
- Autenticacion de usuarios (username/password)
- Broadcast de mensajes a todos los usuarios en una sala
- Mensajes privados entre usuarios
- Crear, unirse, salir de salas de chat
- Listar usuarios online y salas activas
- Persistir historial de mensajes en base de datos
- Desconexion limpia y deteccion de clientes caidos

**Cliente CLI:**
- Conectar al servidor via TCP
- Enviar comandos: /join, /leave, /msg, /list, /quit
- Recibir mensajes en tiempo real
- Mostrar notificaciones de usuarios entrando/saliendo

**Protocolo de comunicacion:**
- Mensajes con formato estructurado (JSON o custom protocol)
- Tipos: LOGIN, MESSAGE, PRIVATE_MSG, JOIN_ROOM, LEAVE_ROOM, LIST_USERS
- Heartbeat para detectar clientes desconectados
- Manejo de mensajes parciales y buffering

### Requisitos tecnicos:
- NIO (Non-blocking I/O) con Selector para escalabilidad
- Thread pool para procesamiento de mensajes
- Sincronizacion correcta de estado compartido (usuarios, salas)
- Sin race conditions, deadlocks o data corruption
- Shutdown graceful del servidor
- Manejo de backpressure (clientes lentos)
- Logging detallado de eventos
- Metricas: usuarios concurrentes, mensajes/segundo, latencia

### Casos de estres:
- 100 clientes conectados simultaneamente
- Rafagas de 1000 mensajes en 1 segundo
- Clientes desconectandose abruptamente
- Servidor detenido y reiniciado sin perder mensajes
