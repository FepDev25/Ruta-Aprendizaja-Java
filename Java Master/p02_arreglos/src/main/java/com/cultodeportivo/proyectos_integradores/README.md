# PROYECTOS INTEGRADORES - P02_ARREGLOS

Esta carpeta contiene proyectos que integran todos los conceptos aprendidos sobre arreglos (arrays) en Java.

## Objetivo

Aplicar de forma práctica y combinada los conocimientos de:

- Declaración e inicialización de arreglos
- Recorrido de arreglos (for, for-each)
- Búsqueda de elementos
- Ordenamiento (burbuja, selección, inserción)
- Modificación de arreglos (insertar, eliminar, desplazar)
- Arreglos combinados y paralelos
- Algoritmos de comparación y análisis
- Arreglos de diferentes tipos (int, String, double, etc.)

## Recomendaciones

1. **Orden sugerido:** Sigue el orden numérico para una progresión adecuada
2. **Practica algoritmos:** Implementa búsqueda y ordenamiento desde cero
3. **No uses Collections:** Usa solo arrays puros para practicar
4. **Optimiza:** Intenta mejorar la eficiencia de tus algoritmos
5. **Prueba casos extremos:** Arrays vacíos, con un elemento, duplicados, etc.
