# PROYECTOS INTEGRADORES - P01_BASICOS

Esta carpeta contiene proyectos que integran todos los conceptos aprendidos en la sección de fundamentos de Java.

## Objetivo

Aplicar de forma práctica y combinada los conocimientos de:

- Fundamentos (tipos de datos, variables)
- Operadores (aritméticos, lógicos, relacionales)
- Strings (manipulación de texto)
- Condicionales (if-else, switch)
- Bucles (for, while, do-while)
- Wrappers y autoboxing
- Entrada/Salida
- Operador instanceof
- Paso por valor/referencia
- Fechas y entorno del sistema
