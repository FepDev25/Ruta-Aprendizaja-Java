# PROYECTOS INTEGRADORES - P03_MATRICES

Esta carpeta contiene proyectos que integran todos los conceptos aprendidos sobre matrices (arrays bidimensionales) en Java.

## Objetivo

Aplicar de forma práctica y combinada los conocimientos de:

- Declaración e inicialización de matrices
- Recorrido de matrices (dobles for anidados)
- Matrices rectangulares y matrices irregulares
- Operaciones matemáticas con matrices
- Búsqueda en matrices bidimensionales
- Transposición y rotación de matrices
- Matrices especiales (identidad, simétrica, triangular)
- Algoritmos de procesamiento de imágenes
- Juegos con tableros (matrices)

## Recomendaciones

1. **Domina los índices:** Filas y columnas pueden ser confusos al principio
2. **Visualiza:** Dibuja las matrices en papel antes de programar
3. **Prueba con matrices pequeñas:** 3×3 o 4×4 antes de escalar
4. **Cuidado con los límites:** ArrayIndexOutOfBounds es común
5. **Usa bucles anidados:** for dentro de for para recorrer
